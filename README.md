# Project Monolith — v4.9.3 — Audio Pass

Construite sur la v4.9.2 validée.

## Nouveaux sons

- `monolith-ambience.ogg` : ambiance en boucle dès l’ouverture de la page ;
- `stone-open.ogg` : ouverture des Huit Entraves ;
- `vathkul-riser.ogg` : montée précédant « Je crois comprendre… » ;
- `blackhole-impact.ogg` : fermeture définitive de la Brèche.

## Mixage

- ambiance discrète avec fondu d’entrée de 2 secondes ;
- nouvelle tentative au premier geste utilisateur si le navigateur bloque l’autoplay ;
- volume de l’ambiance lié au volume général ;
- arrêt progressif de l’ambiance pendant la fermeture finale ;
- impact final prioritaire, sans supprimer totalement le son de destruction historique.
