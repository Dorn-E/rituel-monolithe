# Pack audio intégré — v4.8.1

Les 14 fichiers OGG définitifs sont présents dans ce dossier.

Ils ont été vérifiés avec `ffprobe` avant la livraison :
- codec audio valide ;
- durée lisible ;
- fréquence d’échantillonnage détectée ;
- aucun fichier vide.

Le fichier `audio-manifest.json` contient le rapport technique détaillé.
